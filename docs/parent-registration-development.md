# 父母注册与孩子资料登记：开发验收说明

版本日期：2026-10-06

## 已确认并实现的首版范围

- 产品定位为父母帮助成年子女相亲
- 父母使用手机号和密码，短信接口预留但关闭
- 邀请码和邀请二维码作为选填获客渠道
- 一个账号首版登记一个孩子，账号与档案关系支持以后扩展
- 保留后台审核和人工牵线，提供今日推荐，不加入解锁联系方式、收藏或付费功能
- 研发阶段使用独立新开发库，不迁移旧资料

## 账号与资料模型

`User` 保存父母的登录身份、称呼、邀请来源、账号状态和协议确认版本与时间

`ChildProfile` 保存孩子的档案草稿、当前填写步骤 currentStep、已通过版本、登记归属、版本号和审核状态，性别和照片等字段不再写入父母账号

`UserProfilePending` 每次提交保存独立不可变资料快照、提交版本、子女知情同意确认版本与时间以及审核结果

`UploadedFile` 记录上传父母、孩子档案、上传凭据和完成状态，资料只能引用归属正确且已完成上传的照片

`MatchRecord` 关联双方孩子档案，介绍人可为空，后台只能为账号正常且资料审核通过的孩子录入人工牵线

首版使用 `registrationSlot = primary:<ownerAccountId>` 保证创建幂等，`ownerAccountId` 自身没有唯一约束，未来可扩展新的登记槽位

## 字段与交互

必填：登记父母身份（爸爸或妈妈）、孩子性别、出生日期、身高、现居城市、学历、月收入；收入允许选择暂不填写

选填：孩子称呼、职业、婚姻状况、籍贯、工作城市、购车情况、最多 2 个性格标签、最多 2 个优势标签、介绍、最多 9 张照片

择偶期待均选填：出生年份范围、身高范围、最低学历、现居城市、最多 2 个看重条件标签，留空表示不限

出生日期按上海时区计算周岁，提交时须年满 18 岁；日期须真实有效，择偶范围下限不能超过上限

登录密码为 6–32 位，无字母数字组合限制；注册协议初始选中，父母可以取消，取消后无法提交注册

生日使用 24px 字号、64px 行高的年月日滚动选择器，确认完整日期后自动保存并显示周岁；提交仅确认孩子知情同意，不重复确认成年

职业可快捷点选或自行填写；特点、优势和择偶条件支持换一批，已选标签始终可见；身高与出生年份要求使用上下限下拉选项并约束范围顺序，下拉箭头距右边 18px

移除独立保存草稿按钮，字段修改与切页自动保存；前后端校验错误均使用中文

注册前在 sessionStorage 暂存孩子草稿、登记步骤、父母称呼与手机号、邀请码，不保存登录密码或协议勾选状态；刷新后密码需要重新输入

参考刘老师目录 2、3、5 号图拆成 7 个小步骤：孩子性别 → 学历 → 收入 → 现居城市 → 父母联系方式 → 登录密码 → 选填邀请码及协议确认

创建账号后，已填的四项资料写入草稿，从“爸爸还是妈妈”继续逐项完善；资料编辑分成 23 个单主题页面（含最后核对页），补充资料与择偶期待允许稍后填写，目录可直接定位要修改的项目

登录后点击继续、上一步或目录项目，草稿字段与下一页 currentStep 在同一次带版本校验的请求中保存到服务器，成功后才切页；字段修改后 900ms 自动暂存，刷新、重新登录时恢复已保存的填写位置

网络错误时保留账号专属本机草稿，冲突时要求用户核对后恢复；本机缓存使用稳定的步骤 ID，不按旧页面序号恢复

父母端按参考设计采用粉白背景、珊瑚红操作按钮、粗体无衬线中文标题；正文 20px、问题标题 28–40px、提示文字 18px、普通选项高度至少 68px、主操作按钮 64px、底部导航 18px，保留浏览器缩放；窄屏城市与范围字段竖排，选中项使用颜色和勾选双重提示

登记首屏展示“仅需30秒登记资料”与淡粉爱心背景，人物插画直接从用户提供的设计图裁切；“男孩／找儿媳”和“女孩／找女婿”卡片的文字与圆形箭头独立渲染，支持读屏和键盘操作

点击人物卡片直接进入学历页，注册前仍暂存已选性别与下一页位置；登录后的资料编辑共用相同卡片，保存成功后才进入下一项

提交期间修改草稿，不改变正在审核的快照；再次提交会将之前尚未审核的快照标记为已替代，工作人员不能审核被替代版本

审核通过只更新孩子的已通过资料，不覆盖父母称呼、手机号或登录密码；再次审核前保留上次通过版本

## 今日推荐首页

首页参考刘老师 19 号稿：暖色标题栏、珊瑚红搜索区与四个快捷入口、四格进度卡片、今日推荐列表、橙色完善资料提示；底部入口为今日推荐、我的，孩子资料并入我的，登录后进入首页

`GET /api/v1/recommendations` 仅对父母账号开放，默认推荐与自己孩子性别相反的已审核资料，支持性别、现居城市与职业/介绍关键词筛选；按择偶期待优先排列，同分使用上海日期、父母账号与资料编号固定每日顺序，候选池最多 200 份，每次最多展示 24 份

`GET /api/v1/recommendations/:id` 查看已审核资料详情，始终核对资料已审核、可牵线、父母账号正常且没有注销申请；排除自己的档案，仅返回孩子基础情况、收入区间、婚姻与购车情况、家乡与工作城市、性格优势、介绍、择偶期待、照片预览与登记家长身份类别，不返回手机号、完整生日、父母称呼、照片存储键或草稿

首页数据卡片展示真实登记状态、审核状态、符合筛选条件的资料数与人工牵线记录数；照片模糊预览，无照片时使用注明未上传的插画；新手教程和平台介绍为可操作弹层

点击推荐卡片或查看资料按钮进入 `/recommendations/:id` 独立详情页，参考刘老师 21 号稿采用暖橙背景、登记信息卡与审核标识、大字基础资料、照片、性格优势、介绍、择偶期待和底部固定操作栏；工作地承接之前户籍地字段调整

详情页支持复制当前资料链接（查看仍须登录），按当前推荐列表顺序上一位/下一位切换；列表中只有一位或直接打开链接时不展示切换栏，切换使用替换历史记录，返回直接回推荐列表

从首页进入详情再返回时保留筛选、提示卡关闭状态与浏览位置；进入其他页面时释放首页缓存，避免资料编辑后继续显示旧登记状态

底部展示返回推荐与了解牵线，后者说明当前人工牵线流程并提供自己孩子资料入口，不虚构联系申请、免费次数、会员、实名认证、收藏或电话；不存在或不再可推荐的资料显示中文错误与返回入口

## 我的页面

参考刘老师 1 号稿，使用粉色渐变背景、顶部登记卡片、常用功能三列与其他功能六宫格；顶部根据未登记、草稿、待审核、已通过或需修改显示真实状态，已提交后新增修改会提示再次提交

常用入口为孩子资料、资料预览、今日推荐；其他入口为邀请好友、人工牵线、通知状态、防骗指南、隐私说明与设置，通知状态展示当前审核结果及驳回意见

孩子资料不设独立底部标签，从我的登记卡片或常用功能进入，编辑页面高亮我的，顶部返回按钮回到我的；首页完善资料入口与注册后的逐项登记保持可用

邀请二维码、链接、邀请记录和账号设置放入大字弹层；设置保留父母称呼、脱敏手机号、用户协议、退出登录和注销申请，注销须再次确认，关闭弹层不保存未提交的称呼修改

未接入收藏、解锁、浏览历史或实名认证，不展示虚构记录与认证状态；人工牵线入口说明现有流程，不模拟在线客服或未配置的联系方式

## 主要接口

| 方法 | 路径（前缀 /api/v1） | 说明 |
| --- | --- | --- |
| POST | /auth/register | 注册父母账号，termsAccepted 必须为 true，返回 accessToken 与父母账号 |
| POST | /auth/login | 手机号密码登录 |
| GET | /recommendations、/recommendations/:id | 今日推荐筛选与已审核资料详情 |
| GET | /auth/invite/:code | 校验选填邀请码并显示邀请人称呼 |
| GET | /profile/options | 公开登记选项与确认版本 |
| GET | /profile/draft | 当前父母的孩子档案、草稿和最近提交 |
| PUT | /profile/draft | payload 为草稿字段，expectedRevision 为当前草稿版本，新档案为 0；currentStep 为可选稳定步骤 ID，返回恢复位置与新版本 |
| POST | /profile/submit | expectedRevision、childConsent: true、consentVersion，提交服务器已保存草稿 |
| GET / PUT | /me | 读取父母账号及档案摘要 / 修改父母称呼 |
| GET | /me/invite-code、/me/invites、/me/invite-qrcode | 邀请来源与二维码 |
| POST | /upload/sign、/upload/commit | 上传必传 profileId，记录孩子档案归属 |
| GET | /admin/users、/admin/users/:id | 父母账号列表与详情 |
| GET | /admin/children | 孩子档案列表，approved=true 筛选可牵线资料 |
| GET | /admin/profiles/pending、/admin/profiles/pending/:id | 审核提交快照 |
| POST | /admin/profiles/pending/:id/approve、/reject | 审核，驳回需 reason |
| POST | /admin/matches | profileAId、profileBId、matchedAt、选填 referrerId 与 note |
| POST | /auth/logout | 将当前 token 拉入黑名单 |

档案审核状态：0 草稿、1 待审核、2 通过、3 驳回；提交快照另有状态 4 已被新提交替代

并发修改、重复提交返回 HTTP 409，客户端需读取当前版本并核对，禁止直接用过期版本覆盖

## 短信预留接口

`GET /auth/methods`：password=true、sms=false、smsProvider=disabled

| 路径 | 请求参数 | 当前返回 |
| --- | --- | --- |
| POST /auth/sms/send | phone、purpose（login 或 register） | HTTP 503，短信未启用 |
| POST /auth/sms/verify | phone、purpose、challengeId（UUID）、code（6 位） | HTTP 503，短信未启用 |
| POST /auth/sms/login | 校验参数、termsAccepted，可选 nickname 与 inviteCode | HTTP 503，短信未启用 |

暂不生成真实 challenge、不发送短信、不接受测试验证码登录，也不在前台展示可点击的验证码入口

后续接入须提供真实服务商适配器、签名与模板、发送频率限制、验证码有效期、一次性消费和失败次数限制；仅在这些能力完成后才开启 sms 功能标志

## 数据与开发配置

本地新开发库为 `friends_parent_dev`，旧 `friends` 库未作为新版本运行数据源；Prisma migrations 用于从空库初始化，不提供旧业务数据转换

开发图片使用 mock 本地存储，上传与提交需要父母登录，展示采用 1 小时限时签名链接，MOCK_BASE_URL 保持为空时经前端同源代理展示

管理员与父母 token 使用相同签名服务，但接口按角色隔离，禁用或申请注销的父母不能继续访问，退出后的 token 失效；新 token 使用 friends-parent-v1 audience，旧版本会话需要重新登录

普通运营只看到脱敏手机号，超级管理员详情可看完整号码，孩子照片通过限时链接展示
